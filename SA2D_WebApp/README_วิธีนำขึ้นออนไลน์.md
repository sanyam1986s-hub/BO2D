# SA2D — คู่มือนำโปรแกรมขึ้นออนไลน์ (Web App)

โฟลเดอร์นี้คือชุดไฟล์เว็บแอป SA2D ที่พร้อมนำขึ้นออนไลน์แล้ว ทำเป็น **PWA** (Progressive Web App) — เปิดผ่านลิงก์ได้จากทุกอุปกรณ์ ติดตั้งเป็นแอปบนมือถือ/คอมได้ และ **ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก**

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวโปรแกรม SA2D (ฝัง PWA + คู่มือฉบับเต็มไว้ในตัว) |
| `manifest.json` | ข้อมูลแอปสำหรับติดตั้ง (ชื่อ ไอคอน สี) |
| `sw.js` | Service Worker — ทำให้ใช้งานออฟไลน์ได้ |
| `icons/` | ไอคอนแอปทุกขนาด |
| `คู่มือการใช้งาน_SA2D.html` | คู่มือฉบับเต็ม (เปิดในโปรแกรมได้อยู่แล้วผ่านเมนูช่วยเหลือ) |
| `netlify.toml` / `vercel.json` / `.nojekyll` | ไฟล์ตั้งค่าสำหรับผู้ให้บริการโฮสต์แต่ละเจ้า |

> ⚠️ ต้องอัปโหลด **ทั้งโฟลเดอร์** โดยให้ `index.html` อยู่ที่ระดับบนสุด — ห้ามแยกไฟล์

---

## วิธีที่ 1 — Netlify Drop (ง่ายสุด ไม่ต้องใช้ Git)

1. เข้า https://app.netlify.com/drop
2. ล็อกอิน (สมัครฟรีด้วย Google/GitHub/อีเมล)
3. **ลากโฟลเดอร์ `SA2D_WebApp` ทั้งโฟลเดอร์** ไปวางในกรอบบนหน้าเว็บ
4. รอสักครู่ จะได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app`
5. เปลี่ยนชื่อลิงก์ได้ที่ Site settings → Change site name

เสร็จแล้วเปิดลิงก์นั้นได้จากทุกที่ทันที

---

## วิธีที่ 2 — GitHub Pages (ฟรีถาวร เหมาะทำเป็นลิงก์ประจำ)

1. สมัคร/ล็อกอิน https://github.com
2. กด **New repository** → ตั้งชื่อเช่น `sa2d` → เลือก **Public** → Create
3. หน้า repo กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`) ขึ้นไป → Commit
4. ไปที่ **Settings → Pages**
5. หัวข้อ *Build and deployment* → Source เลือก **Deploy from a branch** → Branch เลือก **main** / โฟลเดอร์ **/(root)** → Save
6. รอ 1–2 นาที ลิงก์จะปรากฏด้านบน: `https://ชื่อผู้ใช้.github.io/sa2d/`

> ไฟล์ `.nojekyll` ในชุดนี้ช่วยให้ GitHub Pages เสิร์ฟไฟล์ได้ครบ ไม่ต้องแก้อะไรเพิ่ม

---

## วิธีที่ 3 — Vercel

1. ล็อกอิน https://vercel.com ด้วย GitHub
2. **Add New → Project** → เลือก repo ที่อัปโหลดไฟล์ไว้ (ตามวิธีที่ 2 ข้อ 1–3)
3. Framework Preset เลือก **Other** → Deploy
4. ได้ลิงก์ `https://ชื่อ.vercel.app`

---

## การติดตั้งเป็นแอป (หลังเปิดลิงก์ออนไลน์แล้ว)

- **Android / Chrome:** จะมีปุ่ม **"⬇ ติดตั้งแอป SA2D"** มุมขวาล่าง กดเพื่อเพิ่มลงหน้าจอ หรือเมนู ⋮ → "ติดตั้งแอป"
- **iPhone / Safari:** กดปุ่มแชร์ ⬆ → "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
- **คอม (Chrome/Edge):** ไอคอนติดตั้ง ⊕ ในแถบที่อยู่ URL หรือปุ่มมุมขวาล่าง

หลังติดตั้ง เปิดใช้งานได้เหมือนแอปทั่วไป และทำงาน **ออฟไลน์** ได้ (เปิดออนไลน์ครั้งแรก 1 ครั้งเพื่อให้แคชไฟล์)

## หมายเหตุสำคัญ

- **ต้องเปิดผ่าน `https://…` เท่านั้น** ระบบ PWA/ออฟไลน์จึงทำงาน (เปิดไฟล์ตรงๆ แบบ `file://` จะไม่ลงทะเบียน Service Worker แต่โปรแกรมยังใช้งานได้ปกติ)
- อัปเดตโปรแกรมภายหลัง: อัปโหลด `index.html` ตัวใหม่ทับ ผู้ใช้จะได้เวอร์ชันใหม่อัตโนมัติเมื่อออนไลน์ (Service Worker ตั้งค่าแบบ network-first)
- ทั้งหมดเป็นไฟล์คงที่ (static) ไม่มีเซิร์ฟเวอร์หลังบ้าน — โฮสต์ฟรีได้ทุกเจ้า ไม่มีค่าใช้จ่าย
