0. รู้จักหน้าจอโปรแกรม (ผังตำแหน่ง 8 โซน)

โซนชื่อหน้าที่
①แถบเมนู (บนสุด)คำสั่งทั้งหมดแบบเมนู: ไฟล์ แก้ไข กำหนด วาด เลือก กำหนดค่า วิเคราะห์ แสดงผล ช่วยเหลือ + ชื่อผู้จัดทำ + ปุ่มสลับภาษา EN
②แถบเครื่องมือปุ่มไอคอนเรียงตามลำดับงาน ซ้าย→ขวา แบ่งกลุ่มมีป้ายกำกับ (ดูตารางข้อ 0.1) ท้ายแถบมี หน่วย, Load Case, ปุ่ม ▶ วิเคราะห์
③แท็บขั้นตอน ①–⑤ลำดับการทำงานหลัก คลิกเพื่อสลับหน้า เลขในวงกลมติ๊กเขียวเมื่อขั้นนั้นทำแล้ว
④แผงเครื่องมือซ้ายปุ่มเครื่องมือประจำแท็บที่เปิดอยู่ (เช่น แท็บ① มี เลือก/Node/Member/Support)
⑤พื้นที่วาด (Canvas)วาด/เลือก/ดูผล — เลื่อนเคอร์เซอร์ผ่านชิ้นส่วนจะเน้นเข้ม+ป้ายชื่อเรืองแสง คลิกดูรายละเอียด
⑥แผงคุณสมบัติขวาช่องกรอกค่าของเครื่องมือที่เลือก (พิกัด แรง หน้าตัด เป้าหมายการใส่แรง ฯลฯ) ทุกช่องตัวเลขทดเลขได้
⑦แถบ Snap (ล่างพื้นที่วาด)เปิด/ปิดการจับจุด: Node · จุดตัด✕ · กึ่งกลาง⊙ · บนเส้น╱ · กริด▦ + ระยะกริด
⑧แถบข้อความ (ล่างสุด)คำแนะนำการใช้เครื่องมือปัจจุบัน ผลของคำสั่งล่าสุด และสถานะการวิเคราะห์
ป้ายหน้าตัด (R): กล่อง "หน้าตัด (R)" ลอยฝั่งขวาของพื้นที่วาด แสดงว่า R1, R2, … คือหน้าตัดอะไร — ลากที่กล่องเพื่อย้ายตำแหน่งได้

0.1 คำสั่งทุกปุ่มบนแถบเครื่องมือ — ตำแหน่ง ลำดับ และวิธีใช้

ปุ่มเรียงซ้าย→ขวา ตามลำดับการทำงานจริง: เปิด/บันทึกไฟล์ → สร้างโมเดล → แก้ไข → ใส่แรง → ดูผล → ส่งออก → มุมมอง

โมดูล 1: 🔺 Roof Truss (โครงหลังคา)

พารามิเตอร์ความหมาย / ตัวอย่าง
แกลเลอรีรูปแบบ (คลิกรูป)10 ทรง: Howe, Warren, Bowstring, Monopitch, Modified Scissors, Half Scissors, Half Parallel Chord, Curved 1, Curved 2, Gambrel
ช่วงกว้าง S / สูงสัน Hระยะฐานถึงฐาน และความสูงยอด เช่น S=12, H=2.4 (ลาด 1:2.5)
จำนวนช่อง (คู่)จำนวนช่องแบ่ง top chord เช่น 8 → ปมรับแรง 9 จุด
heel ซ้าย/ขวาความสูงปลายคาน (0 = ยอดแหลมชนฐาน) กำหนดต่างข้างได้
ยื่นชายคา ซ้าย/ขวาระยะยื่นเลย Support เช่น 0.6 m
ยกท้อง / ความลึกปลาย hdโค้งท้อง Bowstring และความลึกปลายพิเศษ (0 = อัตโนมัติ)
Support ที่ Nodeเว้นว่าง = ปลาย 2 ข้างอัตโนมัติ หรือระบุเลขปม เช่น 2,16
ลายเว็บ + รูปแบบทแยงตั้ง+ทแยง (Pratt/Howe) / Warren / Modified Warren / Fan-Fink และทิศทแยง ⟋⟍ 4 แบบ
หน้าตัด 4 กลุ่มบน/ล่าง/ตั้ง/ทแยง แยกกันได้ — กด 📖 เลือกจากตารางเหล็กมาตรฐาน (L, C, ท่อ ฯลฯ)
ตัวอย่าง: Howe S=12, H=2.4, 8 ช่อง, Load แถว 1: DL ↓GY = 120 kgf/m, แถว 2: LL ↓GY = 50 kgf/m → ตกลง → ได้ Truss พร้อมแรงจุดที่ปม top chord ทั้ง 2 case → ▶ วิเคราะห์ → ดูแรงตามแกน N (น้ำเงินดึง/แดงอัด) และตรวจ Reaction รวม = (120+50)×12 ต่อ case combination

โมดูล 2: 🏢 Building Frame (อาคารหลายชั้น)

พารามิเตอร์ความหมาย / ตัวอย่าง
จำนวนช่วงเสา (bays)เช่น 3 → เสา 4 ต้นต่อชั้น
จำนวนชั้น / ความกว้างช่วง / สูงชั้นเช่น 4 ชั้น × W 6 m × สูง 3.5 m
หน้าตัดเสา / หน้าตัดคานเลือกแยกกัน (สร้างหน้าตัดเพิ่มได้ที่เมนูกำหนด)
ฐานรองรับFixed (ยึดแน่น) หรือ Pin (หมุด)
ตัวอย่าง: 3 bays × 4 ชั้น, Load: DL ↓GY = 800 (น้ำหนักพื้นลงคานทุกชั้น), แถว 2: W →GX = 150 (แรงลม) → ตกลง → ▶ วิเคราะห์ → ดู M ของคาน-เสา และเลือก Combination U2 (1.05D+1.275L+1.6W) ดูผลรวม

โมดูล 3: ➖ Continuous Beam (คานต่อเนื่อง)

พารามิเตอร์ความหมาย / ตัวอย่าง
จำนวนช่วง / ความยาวช่วงเช่น 3 ช่วง × 5 m — Support หมุดซ้ายสุด + ล้อเลื่อนทุกจุดถัดไป
หน้าตัดหน้าตัดเดียวตลอดคาน (แก้รายชิ้นภายหลังได้)
ตัวอย่าง: 3 ช่วง × 5 m, DL ↓GY = 1000 → ตกลง → ▶ วิเคราะห์ → แผนภาพ M เห็นโมเมนต์ลบเหนือ Support กลาง ≈ −wL²/10 และบวกกลางช่วง — ใช้ตรวจกับตารางสัมประสิทธิ์ ACI ได้

โมดูล 4: 🏭 PEB Gable Frame (โกดัง/โรงงาน)

พารามิเตอร์ความหมาย / ตัวอย่าง
Span / Eave / Ridgeช่วงกว้าง เช่น 30 m, สูงเสา 6 m, สูงสัน 7.5 m
แบ่ง rafter ข้างละจำนวนช่วงจันทันต่อข้าง เช่น 4 (ไว้รับแรงจุด/ดูผลละเอียด)
☑ Built-up I อัตโนมัติสร้างหน้าตัดประกอบให้: เสา 500×200×12/6, จันทัน 400×180×10/6 — ติ๊กออกเพื่อเลือกหน้าตัดเอง
ฐานรองรับPin (มาตรฐาน PEB) หรือ Fixed
ตัวอย่าง: Span 30, Eave 6, Ridge 7.5, จันทันข้างละ 4, Load: DL ↓GY = 60, LL ↓GY = 30, W →GX = 80 → ตกลง → ▶ วิเคราะห์ → ดู M ที่หัวเสา (knee) ซึ่งมักวิกฤต และ Envelope E:U สำหรับออกแบบ
เคล็ดลับทุกโมดูล: สร้างแล้วแก้ไขต่อได้ทุกส่วน (ย้าย/แบ่ง/เปลี่ยนหน้าตัด/เพิ่มแรง) • กด Apply ค้างหน้าต่างไว้เพื่อลองหลายขนาดเทียบกัน • ค่าที่กรอกจำไว้ให้ครั้งถัดไป • Truss แปลงแรงเป็นแรงจุดที่ปม top chord อัตโนมัติ, Frame/Beam/PEB ใส่เป็น UDL บนคาน/จันทัน

3. ขั้นที่ ② ใส่แรงกระทำ

ชนิดแรงค่าวิธีใส่

4. ขั้นที่ ③ วิเคราะห์และอ่านแผนภาพ

คลิกแท็บ ③ วิเคราะห์/แผนภาพ หรือปุ่ม ▶ วิเคราะห์ — โปรแกรมวิเคราะห์ทุก Load Case + Combination พร้อมกัน แล้วแสดงแผนภาพ:

แผนภาพความหมาย
N — Axialแรงตามแกน (น้ำเงิน = ดึง, แดง = อัด)
V — Shearแรงเฉือน พร้อมเฉดสีตามความเข้ม
M — Momentโมเมนต์ดัด วาดด้านรับแรงดึง พร้อมเฉดสี
รูปโก่งตัวเส้นโก่งพร้อมเฉดสีตามขนาดการเคลื่อนที่ ปรับตัวคูณขยายได้
Reactionแรงปฏิกิริยาที่จุดรองรับ (ลูกศร + ค่า)

ค่าสำคัญแสดงอัตโนมัติ: max/min พร้อมเส้นชี้ตำแหน่ง x, Probe เลื่อนเมาส์บนเส้นเห็นค่า ณ จุดนั้นทันที, คลิก Member/Node เปิดรายละเอียดเต็ม (กราฟ N/V/M/δ ทุกจุด) ซึ่งส่งออก Excel หรือ รูป PNG ได้จากปุ่มใน pop-up, ปุ่ม 🗔 เปิดหลายแผนภาพพร้อมกัน

5. ขั้นที่ ④–⑤ ตารางข้อมูลและรายงานผล

④ ตารางข้อมูล — Node/Member/หน้าตัด/วัสดุ/แรง ทั้งหมดในรูปตาราง แก้ไขค่าในตารางได้โดยตรง (พิกัดแม่นยำ, เปลี่ยนหน้าตัด ฯลฯ)
⑤ รายงานผล — ตารางแรงปฏิกิริยา การเคลื่อนที่ของ Node แรงภายใน (ปลาย + ค่าสูงสุดในช่วง) ของ Case/Combo/Envelope ที่เลือก พร้อมปุ่มส่งออก

6. Load Case / Combination / Envelope

ค่าเริ่มต้นมี 4 Case: DL, LL, W, E (เพิ่ม/ลบได้) และ Combination ตามกฎกระทรวงกำหนดการออกแบบโครงสร้างอาคารฯ พ.ศ. 2566:

ชุดสูตร
U1–U5 (วิธีกำลัง ข้อ 7)1.4D+1.7L • 1.05D+1.275L+1.6W • 0.9D+1.6W • 1.05D+1.275L+1.0E • 0.9D+1.0E
S1–S2 (หน่วยแรงใช้งาน ข้อ 6)D+L • D+0.75(L+W)
EnvelopeE:U (ห่อหุ้มกลุ่ม U), E:S (กลุ่ม S), E:C (เลือกชุดเอง) — แสดง band ค่า min↔max ทุกจุด

สลับดูผลแต่ละชุดที่ช่อง Load Case ด้านบน — ผล Combination คำนวณแบบ superposition อัตโนมัติ

9. ทฤษฎีการวิเคราะห์และการตรวจสอบความถูกต้อง

วิเคราะห์ด้วย Direct Stiffness Method สำหรับโครงข้อแข็ง 2 มิติ (3 DOF ต่อ Node: ux, uy, θz) — member แบบ Frame ใช้ทฤษฎีคาน Euler–Bernoulli รวมแรงตามแกน, แบบ Truss รับเฉพาะแรงตามแกน, รองรับ moment release (hinge) ที่ปลาย I/J, แรงบน member แปลงเป็น Fixed-End Forces, การแอ่นตัวจาก Hermite shape functions + particular solution, ตรวจจับโครงสร้างไม่เสถียรอัตโนมัติ

โปรแกรมผ่านการตรวจสอบกับคำตอบทฤษฎี 46 กรณี ครอบคลุม:

กรณีทดสอบค่าที่ตรวจ
คานช่วงเดียว UDL / แรงจุด / แรงจุดเยื้อง / โมเมนต์ที่จุดR = wL/2, M = wL²/8, δ = 5wL⁴/384EI, M = Pab/L, δ = Pa²b²/3EIL, R = ±M/L
คานยื่น (แรงปลาย/กลางช่วง)M = −PL, δ = PL³/3EI, θ = PL²/2EI
Fixed-Fixed / Propped cantileverM = −wL²/12, δ = wL⁴/384EI, R = 3wL/8
แรงแผ่สามเหลี่ยม / แผ่เฉพาะช่วงR = W/3, 2W/3, Mmax = wL²/9√3, สมดุลรวม
Truss 2 ท่อน / Portal / member เอียง / เสารับแรงอัดN = −P/2sin45°, ΣF = 0, δ = PL/EA, hinge ปลายคาน
Combination / Envelopesuperposition U1 = 1.4DL+1.7LL ทุกจุด, envelope ครอบทุกชุด pointwise

12. คำถามที่พบบ่อย (FAQ)

Q: วิเคราะห์แล้วขึ้น "โครงสร้างไม่เสถียร"?

ตรวจว่า Support เพียงพอ (โครง 2D ต้องกันการเลื่อน x, y และการหมุนรวมได้), member ต่อถึงกันจริงที่ Node เดียวกัน (ใช้ Snap Node), truss ล้วนต้องมีรูปทรงสามเหลี่ยมมั่นคง

Q: แรงใส่แล้วไม่เห็นในแผนภาพ?

ตรวจช่อง Load Case ว่ากำลังดู case เดียวกับที่ใส่แรง — แรงจะเข้า case ที่เลือกอยู่ตอนป้อน

Q: ค่าโมเมนต์เครื่องหมายไม่ตรงกับที่คำนวณมือ?

โปรแกรมใช้อนุสัญญา M บวก = ดัดให้ท้องคานรับแรงดึง (sagging) และวาดแผนภาพด้านรับแรงดึงตามธรรมเนียมวิศวกรไทย

Q: เปลี่ยนหน่วยแล้วค่าที่กรอกไว้หายไหม?

ไม่หาย — ค่าภายในเก็บเป็นหน่วยเดียวตลอด การเปลี่ยนหน่วยเป็นเพียงการแปลงหน้าจอแสดงผล

Q: ใช้กับมือถือ/แท็บเล็ตได้ไหม?

เปิดได้ แต่แนะนำจอคอมพิวเตอร์ + เมาส์ เพื่อความแม่นยำในการคลิกและลากกรอบเลือก
